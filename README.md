## 할당 단언(!:)
타입스크립트에서 **할당 단언(Definite Assignment Assertions)**은 변수가 초기화되지 않았더라도, 특정 시점 이후 반드시 값이 할당될 것임을 컴파일러에게 보장하는 기능이다.

✅ 기본 문법
변수 선언에서 !(느낌표)를 사용하면 "나는 이 변수가 사용되기 전에 반드시 초기화될 것" 이라고 타입스크립트에게 알려줄 수 있다.
